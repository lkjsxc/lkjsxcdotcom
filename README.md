# lkjsxcdotcom

`lkjsxcdotcom` is the docs-first successor to `kjxlkj`: a small, secure,
multi-space article system genuinely implemented in `.lkjscript`.

## Status

**Current:** repository and production evidence baseline established on
2026-07-24. No application, image, schema, migration, or cutover exists yet.
Do not treat this repository as deployable.

The target is a dark, content-first public feed plus an accessible,
no-JavaScript-capable authenticated editor. Product policy lives in
[docs/product](docs/product/README.md); architecture selection is deliberately
open until the measured experiment program in
[docs/experiments](docs/experiments/README.md) completes.

## Non-goals

The initial release omits uploads, reactions, comments, analytics, search,
federation, billing, themes, native apps, plugins, and legacy implementation
compatibility. Migrated immutable media is continuity work, not a media product.
