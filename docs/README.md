# Documentation Canon

This tree owns active behavior. Historical evidence belongs in Git and private
operator canon, not duplicated here.

## Read by purpose

- [current-state.md](current-state.md): verified truth and known boundaries.
- [product/](product/README.md): public/authenticated behavior and design.
- [architecture/](architecture/README.md): runtime and persistence boundaries.
- [experiments/](experiments/README.md): measured architecture selection.
- [operations/](operations/README.md): migration, deployment, backup, cutover.
- [repository/](repository/README.md): layout and maintenance rules.
- [decisions/](decisions/README.md): accepted/rejected durable choices.

## Status language

- **Current:** implemented and verified.
- **Accepted Target:** selected but not implemented.
- **Experiment:** measured candidate not adopted.
- **Deferred:** intentionally outside this release.
- **Rejected:** considered and not selected.
- **Superseded:** no longer active behavior.

A contract has one owner. Link to it rather than restating it elsewhere.
