# Scope

## Accepted Target

Public: global feed, public-space feed, canonical article pages, health,
readiness, immutable assets, robots, and sitemap.

Authenticated: one-time first-owner setup, access-key login/logout, dashboard,
space selection, create/edit/preview/save/publish/unpublish/archive, session
revocation, credential rotation, and local operator recovery.

Article states are `draft`, `public`, and tombstoned deletion. No nominal state
is allowed without complete route, policy, and rendering behavior.

## Deferred

Uploads, reactions, comments, analytics, search, federation, notifications,
themes, light mode, billing, organizations, native apps, plugins, and generic
page building. Importing immutable legacy media does not enable media management.
